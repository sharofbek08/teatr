# Bosh sahifa uchun animatsiyali rasm

1. GIF yoki animatsiyali WebP faylingizni shu papkaga joylang: `hero.webp`.
2. `src/data/hero.js` faylida `animatedSrc: '/media/hero.webp'` deb yozing.
3. `poster` maydoniga animatsiyaning oddiy muqova rasmini kiriting, masalan `/media/hero-poster.jpg`. Ushbu faylni ham shu papkaga qo‘ying.

`public` URL ichida yozilmaydi. GIF uchun `/media/hero.gif` ishlating. Birgina JPG yoki PNG fayl animatsiya bermaydi.

Animatsiya banner fonini to‘ldiradi. Matn va tugmalar ustida qoladi. To‘xtatish tugmasi animatsiya o‘rniga muqovani ko‘rsatadi; qayta yoqilganda animatsiya qayta boshlanadi. Qurilmada harakatni kamaytirish sozlamasi yoqilgan bo‘lsa, muqova ko‘rinadi. Fayl yuklanmasa ham muqova saqlanadi.

Hozir animatsiyali fayl qo‘shilmagan: avvalgi oddiy fon ko‘rinadi. Yengil, uzluksiz va keskin chaqnashlarsiz animatsiyadan foydalaning.
